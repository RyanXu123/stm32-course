## 目标行为

1. 上电后 LED 默认熄灭。
2. PA0 松开时，LED 熄灭。
3. PA0 稳定按下时，LED 点亮。
4. PA0 松开后，LED 立即回到熄灭。
5. 按住不放时，LED 必须一直亮，不能快速闪烁或反复切换。

电路沿用第 03 讲：

```text
PA0 上拉输入：松开读 1，按下接 GND 读 0
PC13 低电平点亮：写 0 亮，写 1 灭
```

## 必须保留的部分

- GPIOC 和 GPIOA 的时钟都要打开。
- PC13 仍是推挽输出。
- PA0 仍是上拉输入。
- 按键第一次读到 0 后，仍要先 `delay`，再读第二次确认。
- 松手从 0 变回 1 时，也要再确认一次，处理松手抖动。

## 可以自己决定的部分

- 原来的 `level_last`、`led_on` 是否还需要。
- 判断顺序怎么写。
- 用什么变量名，但名字要能说明它保存什么。
