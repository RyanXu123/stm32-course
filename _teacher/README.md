# _teacher —— 本座的东西放这儿

STM32 课程从 2026-10-21 起照 `cpp-demo` 的归属方式分家。

| 夹子 | 装什么 |
|---|---|
| `demo\` | 本座维护的完整示例工程，是讲课源头 |
| `answer\` | 参考答案，主人自己写完再看 |
| `_tmp\` | 当天编译日志、探针和临时产物 |

规矩：

1. 主人的工程只进上层 `stm32-demo\`。
2. 本座的示例工程只进 `_teacher\demo\`。
3. 主人可以复制示例去 `stm32-demo\` 自由修改，但不要直接改 `_teacher\` 里的原工程。
4. 讲义 `.md` 留在课程根目录，不跟工程混在一起。
